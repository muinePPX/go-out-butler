# 讯飞 ASR 接入说明(小白版)

本文件教你一步步开通讯飞语音识别,让机器人能"听懂"你说话。
全程约 15 分钟,完全免费。

---

## 整体流程

```
注册讯飞账号 → 创建应用拿密钥 → 开通语音听写 → 填配置文件 → 装依赖 → 测试
```

---

## 第1步:注册讯飞开放平台账号

1. 打开 https://www.xfyun.cn/
2. 右上角"注册",用手机号注册一个账号
3. 注册后登录,完成实名认证(个人认证即可,需要身份证)

> 实名认证是必须的,不认证无法使用 API。

---

## 第2步:创建应用,拿到三个密钥

1. 登录后进入"控制台" https://console.xfyun.cn/
2. 左侧菜单 → "我的应用" → 点"创建应用"
3. 填写:
   - 应用名称:随便填,如 `出门管家机器人`
   - 应用分类:选"工具应用"
   - 应用描述:随便写一句
4. 创建完成后,进入应用详情页,你会看到三个关键信息:
   - **APPID** (一串数字,如 `5f8a1234`)
   - **APIKey** (32位字符串)
   - **APISecret** (32位字符串)

> 这三个就是你要填进配置文件的密钥,**别泄露给别人**。

---

## 第3步:开通"语音听写"服务并领免费额度

1. 控制台左侧 → "语音听写"(或 https://console.xfyun.cn/services/iat)
2. 点击"开通服务"(免费)
3. 新用户有 **500次/天** 免费额度,还可领取一次 **5万次** 免费包
   - 比赛期间 500次/天 绰绰有余
4. 确认服务状态为"已开通"

---

## 第4步:填写配置文件

1. 在项目 `config/` 目录下,复制模板:
   - 把 `config/xunfei.example.json` 复制一份,重命名为 `config/xunfei.json`
2. 用记事本/VSCode 打开 `config/xunfei.json`,填入你的密钥:

```json
{
  "appid": "5f8a1234",
  "api_key": "你的APIKey(32位)",
  "api_secret": "你的APISecret(32位)",
  "language": "zh_cn",
  "accent": "mandarin"
}
```

3. 保存。

> **安全提示**:`xunfei.json` 已在 `.gitignore` 中,不会被上传到 GitHub,密钥安全。

---

## 第5步:安装依赖

在项目根目录打开终端,运行:

```bash
pip install -r requirements.txt
```

这会装三个包:
- `sounddevice` —— 录音
- `numpy` —— 音频数据处理
- `websocket-client` —— 连接讯飞服务器

> Windows 上 sounddevice 自带 PortAudio,不用额外装。
> 如果装不上,试试 `pip install sounddevice --user`。

---

## 第6步:测试

在项目根目录运行:

```bash
python test_asr.py
```

看到提示后,对着麦克风说一句话(如"我要去运动"),停顿2秒。

**成功的话**会显示:
```
[录音] 完成,时长 2.3秒
[ASR] 识别结果: 我要去运动。
[成功] 识别结果: 我要去运动。
测试通过! voice_input 节点可以使用语音输入了。
```

**如果失败**,看报错信息对照排查:

| 报错 | 原因 | 解决 |
|------|------|------|
| `未找到 config/xunfei.json` | 配置文件没建 | 回到第4步 |
| `讯飞错误码 10005` | APPID错或未开通服务 | 检查APPID,确认已开通语音听写 |
| `讯飞错误码 11200` | 超过免费额度 | 等明天或领免费包 |
| `HMAC signature does not match` | APIKey/APISecret填错 | 重新复制粘贴密钥 |
| `WebSocket错误: ...` | 网络不通 | 检查能否上网,关代理 |
| 录音没反应 | 麦克风没权限或被占用 | 检查系统麦克风设置,关掉其他录音软件 |

---

## 第7步:在节点里使用

测试通过后,`voice_input.py` 节点会自动检测到 `xunfei.json` 并启用语音模式。
直接跑 dataflow 即可,不用改任何代码。

没配密钥时,节点会自动降级为文字输入,不影响演示。

---

## 常见问题

**Q: 识别结果带了句号(如"我要去运动。")?**
A: 正常,讯飞自动加标点。后续 `mclaw_decision` 用关键词匹配,句号不影响。

**Q: 环境很吵,老是误触发?**
A: 打开 `lib/asr_xunfei.py`,调高 `record_pcm` 的 `energy_threshold`(默认250,嘈杂环境调到 400-600)。

**Q: 比赛现场网络不好怎么办?**
A: 讯飞需要联网。现场若断网,节点会自动降级为文字输入。如果想完全离线,后续可加 Whisper 本地方案兜底。

**Q: 开发板上能用吗?**
A: 能。开发板有 Python 和麦克风,装好三个依赖即可。代码不用改。
